# Myuppy Medium 字体材质包 (Myuppy Medium Font Pack)

将 Minecraft 默认字体替换为清晰易读的 **Myuppy Medium** 字体，提升游戏内文字的阅读体验。

## ✨ 功能特色
- **自定义字体**：完美替换游戏内默认字体为 Myuppy Medium。
- **广泛兼容**：支持 Minecraft **1.20 至 26.3** 版本。
- **纯原版支持**：在纯原版（Vanilla）环境下可直接加载使用，无需额外模组。

## 📦 版本兼容说明
由于 Minecraft 在 1.21.9 版本更改了资源包版本声明方式，本字体包提供了不同版本的资源包文件：
- **1.20 ~ 1.21.8**：使用传统 `pack_format` 声明方式。
- **1.21.9 ~ 26.3**：使用新版 `min_format` / `max_format` 声明方式。

## 🔧 安装方法
1. 根据你的游戏版本下载对应的资源包 `.zip` 文件。
2. 将文件放入 `.minecraft/resourcepacks` 文件夹（若文件夹不存在请手动创建）。
3. 启动游戏，进入 **选项 -> 资源包**，找到该资源包并点击启用。
4. 享受全新的字体效果！

## ⚠️ 常见问题 (FAQ)
- **Forge / Fabric 环境下字体不生效？**
  从 1.20.5 开始，部分模组加载器将字体注册改为运行时显式绑定。如果你在模组环境下发现字体未生效，可能需要配合 [Caxton](https://modrinth.com/mod/caxton) 等字体模组使用。
